# Local AI Voice Assistant

A fully local, offline voice assistant with two interfaces (CLI and web),
speech-to-text, text-to-speech, and voice cloning — no cloud APIs anywhere.

```
Text input  ──┐
              ├──▶ Ollama (local LLM) generates a reply
Voice input ──┘         │
   (SenseVoice STT)      ▼
              Kyutai Pocket TTS converts the reply to speech (WAV)
                          │
                          ▼
              Audio is played back automatically
```

- **LLM** — any model served locally via [Ollama](https://ollama.com)
- **STT** — [SenseVoice](https://github.com/FunAudioLLM/SenseVoice) (via `funasr`), for voice input
- **TTS** — [Kyutai's Pocket TTS](https://github.com/kyutai-labs/pocket-tts), a 100M-parameter model that runs on CPU, including **voice cloning**

## Features

- 🧠 **Local LLM** — chat responses generated by any Ollama model you have pulled, with conversation memory.
- 🎤 **Voice input** — speak instead of typing; SenseVoice transcribes your audio locally.
- 🗣️ **Local TTS** — speech generated by Pocket TTS, model loaded once and reused across requests.
- 🧬 **Voice cloning** — record a short sample of your own voice in the browser and have the assistant reply back in it, using Pocket TTS's official cloning pipeline.
- 🔊 **Automatic playback** — every reply is synthesized to WAV and played immediately (CLI) or streamed to the browser (web UI).
- 🌐 **Two interfaces** — a terminal CLI (`main.py`) and a full web UI with mic recording (`server.py` + `web/index.html`).
- ⚙️ **Configurable** — LLM model, TTS voice, STT device/language, and paths all live in `.env`.
- 🧩 **Modular code** — config, LLM, STT, TTS, and audio playback are separate, testable modules shared by both interfaces.
- 🛡️ **Error handling** — clear, actionable messages at every stage (Ollama unreachable, model not pulled, TTS/STT load failures, playback issues).

## Prerequisites

1. **Python 3.10–3.14** and **PyTorch 2.5+** (CPU build is fine — nothing here requires a GPU).
2. **Ollama** installed and running locally: <https://ollama.com>

   ```bash
   ollama serve
   ollama pull llama3.2   # or any other model you'd like to use
   ```
3. **ffmpeg** — required to decode browser-recorded audio (WebM/Opus) for both STT and voice cloning. No system-wide install needed; the project bundles one automatically via `imageio-ffmpeg` on first run of `server.py`.
4. **(Voice cloning only)** A free Hugging Face account:
   - Accept the model terms at <https://huggingface.co/kyutai/pocket-tts>
   - Log in locally: `hf auth login` (paste an access token from <https://huggingface.co/settings/tokens>)

## Installation

```bash
git clone <this-repo-url>
cd local-ai-voice-assistant

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

> doesn't pull a working PyTorch build for your platform, install it first
> from <https://pytorch.org/get-started/locally/>, then re-run the command above.

## Configuration

Copy the example env file and adjust as needed:

```bash
cp .env.example .env
```

| Variable            | Default                        | Description                                                  |
|---------------------|---------------------------------|----------------------------------------------------------------|
| `OLLAMA_MODEL`      | `llama3.2`                      | Ollama model to use (must be pulled already)                    |
| `OLLAMA_HOST`       | `http://localhost:11434`        | Ollama server URL                                                 |
| `SYSTEM_PROMPT`     | (short assistant persona)       | System prompt sent to the LLM                                      |
| `TTS_VOICE`         | `alba`                          | Default Pocket TTS voice — preset name, local WAV/safetensors path |
| `TTS_LANGUAGE`      | `english`                       | Pocket TTS language model to load                                    |
| `STT_MODEL`         | `iic/SenseVoiceSmall`           | SenseVoice model ID                                                    |
| `STT_DEVICE`        | `cpu`                           | Device for STT inference (`cpu` or `cuda:0`)                            |
| `STT_LANGUAGE_CODE` | `auto`                          | STT language hint (`auto`, `zh`, `en`, `yue`, `ja`, `ko`)                 |
| `OUTPUT_DIR`        | `./output`                      | Directory where generated WAV files are saved                              |
| `OUTPUT_FILENAME`   | `response.wav`                  | Filename reused for each reply (CLI mode)                                   |
| `VOICES_DIR`        | `./voices`                      | Directory where cloned voice embeddings (`.safetensors`) are saved           |
| `EXIT_COMMANDS`     | `exit,quit,bye,:q`              | Comma-separated words that end the session (CLI mode)                         |

See `.env.example` for the full list of built-in Pocket TTS voice presets.

## Usage

### CLI mode (text only)

```bash
python main.py
```

```
You: What's the capital of France?
Assistant: The capital of France is Paris.
[audio plays automatically]

You: exit
Goodbye!
```

### Web mode (text, voice input, and voice cloning)

```bash
python server.py
```

Open **http://localhost:5000** in your browser (must be `localhost`/`127.0.0.1` — mic access requires a secure context).

- **Type or speak** — use the text box, or hit 🎤 **Record** to ask by voice (transcribed locally via SenseVoice).
- **Clone your voice** — read the sample passage shown on the page, click **Record Sample**, and your voice is processed and instantly activated as the assistant's TTS voice. It's also saved permanently for future sessions.
- **Switch voices** anytime from the dropdown — built-in presets or any voice you've cloned.

## How it works

1. **`app/config.py`** loads all settings from environment variables / `.env`, with sensible defaults and validation.
2. **`app/llm.py`** wraps the official `ollama` Python client, keeps a running conversation history in memory, and checks on startup that the server is reachable and the model is available.
3. **`app/stt.py`** wraps `funasr`'s SenseVoice model, loaded once at startup and reused for every transcription.
4. **`app/tts.py`** wraps the official Pocket TTS Python API. The model is loaded once; voices (presets or cloned) can be swapped at runtime via `set_active_voice()`. Voice cloning uses Pocket TTS's official `get_state_for_audio_prompt()` → `export_model_state()` flow to turn a short recording into a reusable `.safetensors` embedding.
5. **`app/audio.py`** plays WAV files locally via `sounddevice`/`soundfile` (CLI mode only — the web UI plays audio in-browser).
6. **`app/cli.py`** and **`server.py`** are two thin interfaces sharing the same backend modules — one for the terminal, one exposing a REST API + browser UI (`web/index.html`) with `MediaRecorder`-based mic capture.
7. Browser-recorded audio arrives as WebM/Opus; both STT and voice cloning convert it to WAV via a bundled `ffmpeg` binary before processing (no system install required).

## API endpoints (web mode)

| Method | Endpoint            | Purpose                                                        |
|--------|----------------------|-------------------------------------------------------------------|
| `POST` | `/api/chat`           | Send `text` or `audio` → returns `{ reply, audio_url }`             |
| `GET`  | `/api/voices`          | List preset + cloned voices, and the currently active one            |
| `POST` | `/api/clone-voice`      | Upload an `audio` sample + `voice_name` → clones and activates it     |
| `POST` | `/api/use-voice`         | Switch active voice: `{ "voice": "<name>" }`                            |

## Troubleshooting

- **`Could not reach Ollama at 'http://localhost:11434'`**
  Make sure `ollama serve` is running, or that `OLLAMA_HOST` points at the correct address.
- **`Model 'x' was not found on the Ollama server`**
  Run `ollama pull <model-name>` first.
- **`The 'funasr'/'pocket-tts' package is not installed`**
  Run `pip install -r requirements.txt`, making sure your virtual environment is active.
- **`Mic error: Cannot read properties of undefined (reading 'getUserMedia')`**
  Open the page via `http://localhost:5000`, not an IP address — mic access requires a secure context.
- **`Format not recognised` / `WinError 2` on transcription or voice cloning**
  ffmpeg isn't resolving correctly. The project auto-installs a local copy on first run; delete the `.ffmpeg_bin/` folder and restart `server.py` to regenerate it.
- **`We could not download the weights for the model with voice cloning...`**
  Voice cloning requires accepting the gated model's terms and logging in: visit <https://huggingface.co/kyutai/pocket-tts>, accept the terms, then run `hf auth login` locally.
- **No sound plays / playback error (CLI mode)**
  Confirm your system has a working default audio output device and that `sounddevice`/`soundfile` installed correctly.

## Voice cloning — usage notice

Only clone voices with the speaker's explicit, informed consent. Per Pocket TTS's terms, voice cloning must not be used for impersonation without consent, misinformation, or any deceptive, unlawful, or privacy-invasive purpose.

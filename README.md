# Local AI Voice Assistant

A fully local, offline voice assistant CLI:

```
User types text
     │
     ▼
Ollama (local LLM) generates a reply
     │
     ▼
Kyutai Pocket TTS converts the reply to speech (WAV)
     │
     ▼
Audio is played back automatically
```

No cloud APIs are used anywhere — the LLM runs through your local
[Ollama](https://ollama.com) server, and speech synthesis runs through
[Kyutai's Pocket TTS](https://github.com/kyutai-labs/pocket-tts), a
100M-parameter TTS model small enough to run entirely on CPU.

## Features

- 🧠 **Local LLM** — chat responses generated by any Ollama model you have pulled.
- 🗣️ **Local TTS** — speech generated by Pocket TTS, model loaded once and reused.
- 🔊 **Automatic playback** — every reply is saved as a WAV file and played immediately.
- ⚙️ **Configurable** — LLM model, TTS voice, and other settings live in `.env`.
- 🧩 **Modular code** — config, LLM, TTS, and audio playback are separate, testable modules.
- 🛡️ **Error handling** — clear, actionable messages if Ollama or Pocket TTS aren't set up correctly.

## Prerequisites

1. **Python 3.10–3.14** (required by Pocket TTS) and **PyTorch 2.5+** (CPU build is fine —
   Pocket TTS does not need a GPU).
2. **Ollama** installed and running locally: <https://ollama.com>

   ```bash
   ollama serve
   ollama pull llama3.2   # or any other model you'd like to use
   ```

## Installation

```bash
git clone <this-repo-url>
cd local-ai-voice-assistant

python -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate

pip install -r requirements.txt
```

> **Note:** `pocket-tts` requires PyTorch. If `pip install -r requirements.txt`
> doesn't pull in a working PyTorch build for your platform, install it first
> following the instructions at <https://pytorch.org/get-started/locally/>,
> then re-run the command above.

## Configuration

Copy the example env file and adjust as needed:

```bash
cp .env.example .env
```

| Variable         | Default                        | Description                                            |
|------------------|---------------------------------|----------------------------------------------------------|
| `OLLAMA_MODEL`   | `llama3.2`                      | Ollama model to use (must be pulled already)              |
| `OLLAMA_HOST`    | `http://localhost:11434`        | Ollama server URL                                          |
| `SYSTEM_PROMPT`  | (short assistant persona)       | System prompt sent to the LLM                               |
| `TTS_VOICE`      | `alba`                          | Pocket TTS voice preset name, local WAV path, or `hf://...` |
| `TTS_LANGUAGE`   | `english`                       | Pocket TTS language model to load                            |
| `OUTPUT_DIR`     | `./output`                      | Directory where generated WAV files are saved                |
| `OUTPUT_FILENAME`| `response.wav`                  | Filename reused for each generated reply                      |
| `EXIT_COMMANDS`  | `exit,quit,bye,:q`              | Comma-separated words that end the session                     |

See `.env.example` for a list of built-in Pocket TTS voices.

## Usage

```bash
python main.py
```

Example session:

```
============================================
  Local AI Voice Assistant (Ollama + Pocket TTS)
============================================
Type your message and press Enter.
Type 'exit' (or 'quit' / 'bye') to stop.

Connecting to Ollama at http://localhost:11434 (model: llama3.2)...
Ollama is ready.
Loading Pocket TTS (voice: alba, language: english)...
Pocket TTS is ready.

You: What's the capital of France?
Assistant: The capital of France is Paris.
[audio plays automatically]

You: exit
Goodbye!
```

The most recent reply's audio is always saved to
`OUTPUT_DIR/OUTPUT_FILENAME` (default: `./output/response.wav`).

## How it works

1. **`app/config.py`** loads all settings from environment variables /
   `.env` using `python-dotenv`, with sensible defaults and validation.
2. **`app/llm.py`** wraps the official `ollama` Python client, keeps a
   running conversation history in memory, and checks on startup that
   the server is reachable and the model is available.
3. **`app/tts.py`** wraps the official Pocket TTS Python API
   (`from pocket_tts import TTSModel`). The model and the chosen voice
   state are loaded exactly once, in `PocketTTSEngine.load()`, and
   reused for every subsequent reply — loading them is the slow part,
   generation is fast.
4. **`app/audio.py`** plays the resulting WAV file locally using
   `sounddevice` + `soundfile` — no external media player required.
5. **`app/cli.py`** ties it all together into a simple `while True`
   input loop with error handling at every stage, so a single failed
   turn (e.g. Ollama hiccup) doesn't crash the whole session.

## Troubleshooting

- **`Could not reach Ollama at 'http://localhost:11434'`**
  Make sure `ollama serve` is running, or that `OLLAMA_HOST` points at
  the correct address.
- **`Model 'x' was not found on the Ollama server`**
  Run `ollama pull <model-name>` first.
- **`The 'pocket-tts' package is not installed`**
  Run `pip install pocket-tts` (or `pip install -r requirements.txt`).
- **No sound plays / playback error**
  Confirm your system has a working default audio output device, and
  that `sounddevice`/`soundfile` installed correctly (they depend on
  PortAudio and libsndfile respectively, which are usually bundled by
  pip but occasionally need a system package on Linux, e.g.
  `sudo apt install libportaudio2`).
